# API

Aplikasi saat ini berorientasi server-rendered dan belum membuka REST API publik penuh.

Endpoint utama:

- `/login`
- `/logout`
- `/dashboard`
- `/calendar`
- `/search`
- `/compliance`
- `/reports`
- `/reports/export.csv`
- `/audit-logs`
- `/settings`
- `/users`
- `/roles`
- `/notifications`
- `/assistant`
- `/modules/<module>`
- `/modules/<module>/new`
- `/modules/<module>/<id>/edit`
