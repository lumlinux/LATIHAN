# AI Secretary

AI Secretary saat ini bekerja sebagai assistant ringkasan berbasis data aplikasi.

Kemampuan saat ini:

- merangkum permit
- merangkum kontrak / MOU
- merangkum task
- merangkum surat
- merangkum tembusan / compliance

Prinsip keamanan:

- AI tidak mendapat akses database langsung
- AI mengikuti permission user yang sedang login
