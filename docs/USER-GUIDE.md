# User Guide

Alur dasar penggunaan:

1. Login sesuai akun dan organization.
2. Buka dashboard untuk melihat ringkasan kerja.
3. Kelola modul yang relevan seperti document, permit, contract, task, meeting, atau surat.
4. Gunakan `Global Search` untuk mencari data lintas modul.
5. Gunakan `AI Secretary` untuk meminta ringkasan status kerja.
